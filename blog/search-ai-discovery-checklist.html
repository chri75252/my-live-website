The Forge · Site & Search

A practical search and AI-discovery checklist.

This is a supporting technical resource—not the main editorial subject of The Forge.

Published 2026-07-27Updated 2026-07-27Publisher: The Blacksmith Market Ltd

Key takeaway: AI-assisted search does not require a special “AI SEO” layer. A crawlable site, accurate text, clear internal links, useful content and structured data that matches the page remain the foundation.

1. Establish one canonical website

Choose one HTTPS host, redirect alternatives where possible and use self-referencing canonical tags. Internal links, sitemap entries and social metadata should point to the same URLs.

2. Keep important information in HTML

Animation and imagery can improve the experience, but search systems still need accessible text explaining the company, page subject, products, services or resources.

3. Publish content worth retrieving

Useful articles should answer a real question and add a framework, comparison, test, example or checklist. Publishing generic summaries at scale is not a substitute for expertise or evidence.

4. Build internal topic relationships

Link the homepage, commercial pages and related resources naturally. Topic clusters help visitors and crawlers understand how pages relate.

5. Use structured data accurately

Organisation, Article, Breadcrumb and visible FAQ markup can clarify page meaning. Do not add Product, Review or Service markup for things that are not actually present.

6. Separate search access from training policy

Search crawlers and model-training controls are separate decisions. The current site uses a minimal public crawl rule while a more detailed policy remains an owner decision.

7. Measure with normal search tools

Use Search Console to inspect rendered HTML, selected canonicals, sitemap processing, indexing and query performance. New pages should be assessed over time rather than judged after a few days.

Checklist

  • One canonical HTTPS host.
  • Working robots and sitemap.
  • Important text visible without relying on canvas.
  • Unique titles and descriptions.
  • Accurate JSON-LD.
  • Useful internal links.
  • Relevant images and alt text.
  • No invented authors, reviews or capabilities.
  • Search Console inspection after release.
