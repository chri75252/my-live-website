# Visual Target and Acceptance Criteria

## Target object
The homepage persistent Three.js component should look as close as possible to the object seen in the reveal video / reveal reference frames.

## Persistent component target characteristics
### Geometry
- glossy near-black central sphere,
- approximately three dominant intersecting bronze/copper orbital rings,
- restrained outer circular / spherical cage,
- subtle internal irregular wire network,
- small metallic node spheres placed sparingly and intentionally,
- clean premium silhouette.

### Materials
- central sphere: black lacquer / polished dark finish,
- rings: muted bronze / copper / rose-bronze metallic tone,
- no harsh cheap neon orange effect,
- reflections should read as reflections, not painted white blobs,
- metallic response should be controlled and premium.

### Lighting
- cinematic studio-like lighting,
- dark moody environment,
- restrained warm highlights,
- clean reflective highlights on the sphere,
- no blown-out glow.

### Motion
- subtle, premium, frame-rate-independent movement,
- orbital/ring motion must feel elegant, not chaotic,
- highlight motion should help the sphere feel alive,
- reduced-motion support must remain intact.

## Reveal target characteristics
- scroll-controlled reveal must remain smooth,
- no obvious frame skipping,
- the final reveal frame must land cleanly before homepage exposure,
- the reveal object should visually connect to the persistent homepage object,
- the reveal-to-homepage transition must feel deliberate and polished.

## Acceptance test
The work is acceptable only if all of the following are true:
1. The persistent homepage armillary clearly resembles the reveal object.
2. The reveal scroll no longer feels laggy/skippy compared with earlier better states.
3. The handoff to the homepage is smoother than the current broken/regressed state.
4. The final live result looks more premium, not merely more complex.
5. Mobile and desktop both remain visually coherent.
